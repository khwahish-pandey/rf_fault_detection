# Machine Learning-Based RF Fault and Anomaly Detection Using XGBoost, Autoencoder and SDR

## Objective
Develop a system that classifies known RF faults using XGBoost and detects previously unseen anomalies using an Autoencoder.

## Data Sources
- Synthetic RF signals generated using GNU Radio
- External RF signal dataset from Kaggle
- Real SDR recordings for validation, if hardware is available

## Project Pipeline
1. RF fundamentals and project setup
2. Normal signal generation
3. RF fault simulation
4. IQ dataset creation
5. FFT, PSD and spectrogram analysis
6. RF feature extraction
7. Dataset preparation
8. XGBoost classification
9. Autoencoder training
10. Anomaly threshold calibration
11. Model fusion
12. Streamlit dashboard
13. Testing under different SNR conditions
14. Real SDR validation
15. Final evaluation
16. Report, presentation and demonstration

## Reproducibility
All experiments should document signal parameters, sampling rates, data labels, feature definitions and model settings.
